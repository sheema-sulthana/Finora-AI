# Finora AI Launch

Design and develop a premium, modern, responsive fintech landing page for an AI-powered personal finance platform called "Finora AI".

The website should look like a real startup product, not a college project. Take inspiration from modern fintech companies such as Stripe, Revolut, Ramp, Linear, and CRED, while keeping the design unique.

Use React + Tailwind CSS with smooth animations, glassmorphism, gradient effects, and professional UI/UX.
